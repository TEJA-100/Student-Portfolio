## Three Git Commands I Learned
1. `git clone <url>` — creates a local copy of a remote repository.
2. `git branch <name>` — creates a new branch for independent development.
3. `git push origin <branch>` — uploads local branch commits to the remote repository.

## Purpose of GitHub
GitHub hosts Git repositories online and supports collaboration, code review, and project sharing. It enables developers to work together on projects from anywhere, track changes, and manage contributions through features like pull requests and issues.

## One Benefit of Branches
Branches let developers work on new features or fixes in isolation without affecting the main codebase, making it safe to experiment and collaborate without breaking production code.
